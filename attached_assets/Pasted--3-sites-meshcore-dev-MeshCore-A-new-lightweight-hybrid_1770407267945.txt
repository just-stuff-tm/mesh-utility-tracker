For "Discover Nearby Nodes" via BLE, the MeshCore protocol uses a specialized request that triggers a Zero-Hop Advert broadcast. 
The Exact Command
When you tap "Discover Nearby Nodes" in the MeshCore app, the following command is sent to your companion radio:
Component 	Value (Hex)	Protocol Name
Command ID	0x27	CMD_SEND_TELEMETRY_REQ
Target Address	0xFFFF	Broadcast Address
How It Works
Request: Your device sends CMD_SEND_TELEMETRY_REQ to the broadcast address (0xFFFF).
Broadcast: This instructs your companion radio to send a Zero-Hop Advert packet over the air.
Response: Any repeater or sensor in direct radio range that receives this packet will immediately broadcast its own telemetry in response.
Discovery: Your radio receives these responses and pushes a PUSH_CODE_STATUS_RESPONSE (0x87) back to the app, which then populates your "Nearby Nodes" list. 
Implementation in MeshCore JS
In a JavaScript environment using the MeshCore library, you can manually trigger this discovery cycle with:
javascript
// Triggers a broadcast telemetry request for discovery
await meshcore.commands.send_telemetry_req(0xFFFF);
Use code with caution.

Constraints to Remember
Firmware Version: This active discovery feature typically requires repeaters to be running firmware v1.10 or later.
Node Type: This command currently discovers repeaters and sensors; discovering other "companions" is intentionally disabled for privacy unless they have opted-in.
Physical Range: Since it is "Zero-Hop," it only finds nodes that your radio can hear directly without going through another repeater.
